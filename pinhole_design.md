# Pinhole Design - Superseded Index

This file used to contain a combined pinhole camera specification. The project is now split into separate module documents:

- [camera_design.md](camera_design.md) - system-level architecture and locked decisions
- [film_back_design.md](film_back_design.md) - film transport, gate, dark slide, body interface, and sprocket auto-lock
- [simple_body_design.md](simple_body_design.md) - simple 50mm-depth body for pinhole use
- [lens_design.md](lens_design.md) - M42 pinhole module and future lens module notes

Use those files as the current source of truth. Do not use older combined pinhole-body/film-transport notes for modeling.
