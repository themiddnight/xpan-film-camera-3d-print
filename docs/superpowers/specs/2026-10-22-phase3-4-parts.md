# Phase 3-4 Parts: Film Back, Body and Pinhole Module

**Date:** 2026-10-22
**Status:** Working plan for phases 3 and 4 of the [redesign roadmap](2026-10-21-redesign-roadmap-design.md)

## 1. Goal

Model every remaining printed part of the film back, the simple body and the M42 pinhole module in
build123d. Add every bought part as a reference solid so the assembly reads as the real camera. Show
all of it in the Vite + React + react-three-fiber viewer, with each mechanism movable.

Sources of truth for dimensions: [film-back.md](../../design/film-back.md) section 17,
[simple-body.md](../../design/simple-body.md) sections 7-8, [lens.md](../../design/lens.md) section 2
and [bom.md](../../bom.md). Where a doc gives a range or leaves a value open, pick one, put it in
`cad/params.py` with a comment, and list it in the part module's docstring.

Each bought part lives in the module of the printed part it fits, so the two never disagree.
Bought parts are simplified solids at their true size and position (a rod is a cylinder, a spring a
helix or a tube, the film a 0.13mm sheet along the S path with its perforations). They are not printed
and have no STL.

## 3. Registry shape

Each part module exports `PARTS: dict[str, PartSpec]`. `cad/parts/__init__.py` merges them.

```python
@dataclass(frozen=True)
class PartSpec:
    build: Callable[[Camera], Part]
    place: Callable[[Camera], Location]   # assembled pose; identity if built in camera coordinates
    group: Group                          # "film-back" | "body" | "pinhole"
    kind: Kind                            # "printed" | "bought"
    color: str
    print_rotation: tuple[float, float, float] | None = None  # required for printed parts
```

Parts may be built directly in camera coordinates (place = identity) or around their own axis and
placed, as `sprocket` is. Every part is built in its assembled, at-rest pose: cover closed, body
attached, button up, pawl in the notch, rewind knob down, dark slide in, shutter closed.

## 4. Mechanisms

`cad/mechanisms.py` lists the moving systems. Each has a value from 0 to 1 and drives parts by
rotation about an axis or a slide along one, in camera coordinates.

| Id | Label | Drives at value 1 |
|---|---|---|
| `advance` | Advance one frame | `sprocket` +360 deg about its pin; `takeup_spool`, `drive_collar`, `advance_knob`, `takeup_shaft` turn to wind 66.5mm at the mid-roll diameter |
| `release` | Press release button | `release_button` -2.5mm in Z; `pawl` turns about its pivot pin so the tip lifts 2.5mm |
| `pawl_ride` | (internal) | `pawl` turns so its nose rides on the cam face between clicks; used by the frame cycle only |
| `rewind` | Lift rewind knob | `rewind_knob`, `rewind_fork`, `rewind_shaft` +8mm in Z |
| `turn_buttons` | Turn the cover latches | `turn_button_left/right` turn 90 deg about their screws to release the cover |
| `cover` | Open rear cover | `rear_cover`, its pressure pad and the `slide_holder` turn about the hinge pin, 0 to 100 deg; the turn buttons stay on the shell |
| `dark_slide` | Pull dark slide | `dark_slide` slides up out of its slot by its own height |
| `slide_carry` | (internal) | `dark_slide` jumps from its pulled pose to 3mm over the cover top, above its holder; set by `slide_stow`'s requires |
| `slide_stow` | Stow dark slide on the cover | `dark_slide` drops 66mm into the `slide_holder` onto its stop bar; needs the slide pulled and carried |
| `shutter_lock` | Unlock shutter | `shutter_lock` turns 25 deg about its pivot so its tooth leaves the knob |
| `shutter` | Open shutter | `shutter_blade` and `shutter_knob` slide +X 10mm to uncover the pinhole; needs the lock turned |
| `finder_front` | Fold front finder frame | `viewfinder_front_frame` turns -90 deg about its hinge pin, forward onto the body top |
| `finder_rear` | Fold rear finder frame | `viewfinder_rear_frame` turns -90 deg about its hinge pin onto the folded front frame; needs the front frame folded |

## 5. Manifest (export.py writes it, the viewer reads it)

```json
{
  "glb_unit_scale": 1000,
  "film_advance_mm": 66.5,
  "parts": [{ "name": "...", "glb": "glb/<name>.glb", "group": "film-back", "kind": "printed",
              "color": "#...", "volume_mm3": 0, "size_mm": [0, 0, 0] }],
  "mechanisms": [{ "id": "advance", "label": "Advance one frame",
                   "readout": { "per_unit": 66.5, "unit": "mm of film" },
                   "drives": [{ "part": "sprocket", "kind": "rotate", "axis": [0, 0, 1],
                                "origin": [55, 10.52, 0], "amount": 360 }] }]
}
```

`amount` is degrees for `rotate` and millimetres for `slide`, at mechanism value 1. `readout` is
optional. The viewer composes every drive on a part, in manifest order.

## 6. Checks

- Each module adds geometry checks for what its parts must get right, in
  `cad/check_areas/<module>.py`, registered with `checklib.check`. Each new check gets a seeded
  error in `cad/tests/test_<module>.py` that the check catches.
- Assembly checks in `cad/checks.py`: no two placed solids overlap except the named press fits and
  intended contacts; every printed part fits 180 x 180mm in its print orientation; the pinhole plane
  sits 50.0 +/- 0.3mm from the film plane; the gate is 65.0 x 24.0mm and centred.

`Pawl` holds an interface block (pivot height, cheek gap, spring shelf, button collar and lug) that both
the shell and the transport parts read. It was fixed before modeling; neither stream changes it alone.

The lead merges each branch into `parts-phase3-4`, writes `cad/mechanisms.py` and the assembly checks,
and runs the interference check across everything. Clashes found there go back as fix rounds.
